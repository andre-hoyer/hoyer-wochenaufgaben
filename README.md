# Max & Matilda – Wochenaufgaben

Eine kleine, installierbare Web-App für die täglichen Schulaufgaben von Max und Matilda.

## GitHub Pages

1. Den Inhalt dieses Ordners in ein neues GitHub-Repository hochladen.
2. Unter **Settings → Pages** bei **Build and deployment** die Quelle **Deploy from a branch** auswählen.
3. Branch **main**, Ordner **/(root)** wählen und speichern.
4. Den anschließend angezeigten Link öffnen.

Die Häkchen werden pro Kalenderwoche lokal auf dem jeweiligen Gerät gespeichert. Die App funktioniert nach dem ersten Laden auch offline.
