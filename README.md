# Max & Matilda – Wochenaufgaben V2

Eine installierbare Netlify-Web-App mit gemeinsamem Login und Online-Stand, Wochenziel, Verlauf, flexiblen Aufgaben und Datensicherung.

## GitHub Pages

1. Den Inhalt dieses Ordners in ein neues GitHub-Repository hochladen.
2. Unter **Settings → Pages** bei **Build and deployment** die Quelle **Deploy from a branch** auswählen.
3. Branch **main**, Ordner **/(root)** wählen und speichern.
4. Den anschließend angezeigten Link öffnen.

Der gemeinsame Stand wird mit Netlify Blobs synchronisiert und zusätzlich lokal zwischengespeichert. Der Zugriff ist durch einen gemeinsamen Benutzernamen, ein Passwort und ein sicheres Sitzungscookie geschützt. Die Einrichtung ist in `NETLIFY-EINRICHTUNG.md` beschrieben.
